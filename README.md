## Overview

HydraVault is a multi-script toolkit organized around Python and Shell automation.  
The project is intended for learning, research, and authorized security evaluation in controlled environments.

In practical terms, it is designed as:
- an educational codebase
- a controlled test utility
- a defensive research project

- Multi-file project layout

## Repository Structure

Main files in this repository:

- `README.md` — project documentation
- `requirements.txt` — Python dependencies
- `starter.sh` — startup/helper script
- `tool+main.sh` — primary shell workflow
- `collect_personal.sh` — auxiliary shell script
- `personal_generator.py` — Python helper module
- `advanced+cracker.py` — advanced Python module
- `advanced+++cracker.py` — additional advanced Python module

## Installation

### 1) Clone the repository
```bash
git clone https://github.com/NRXQuantum/HydraVault.git
cd HydraVault
```

### 2) Create a virtual environment
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3) Install dependencies
```bash
pip install -r requirements.txt
```

### 4) Make shell scripts executable
```bash
chmod +x *.sh
```
